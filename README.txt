# Horrorómetro

Página de ranking personal de películas, series y criaturas de Guillermo Reyes.

IMPORTANTE: sube el CONTENIDO de esta carpeta a la raíz del repositorio `reyesdss/Horrorometro`.

La versión actual lleva CSS y JavaScript dentro de `index.html`, para evitar que el diseño falle por rutas o por la carga de una hoja externa.
