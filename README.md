# Horrorómetro

Esta versión es autocontenida: `index.html` incluye el CSS y JavaScript, además de una copia embebida del catálogo. Por eso puede abrirse directamente en Chrome desde el disco y también funciona en GitHub Pages.

Archivos principales:
- `index.html` — página completa.
- `data/catalog.json` — catálogo de referencia.
- `peliculas.csv` — archivo sencillo para editar tu ranking.
